        │   ├─ IF healthy?

        │   │

        │

Start LM Studio Check
    │
    ├─ OPTION A: Check LOCAL LM Studio (host:1234)
    │   │
    │   ├─ curl http://localhost:1234/
    │   │
    │   ├─ IF responds?
    │   │   └─ ✅ YES → Use LOCAL (PREFERRED)
    │   │   └─ Docker containers use: http://host.docker.internal:1234/v1
    │   │   └─ Continue
    │   │
    │   └─ IF FAILED → Try next option
    │
    ├─ OPTION B: Check CONTAINER LM Studio (docker:1234)
    │   │
    │   ├─ docker ps --filter "name=lmstudio" --filter "status=running"
    │   │
    │   ├─ IF running?
    │   │   └─ ✅ YES → Use CONTAINER
    │   │   └─ Continue
    │   │
    │   ├─ IF exited?
    │   │   │
    │   │   ├─ Check exit code
    │   │   │
    │   │   └─ IF exit 139 (model missing)?
    │   │       └─ Try next option
    │   │
    │   └─ IF NOT running → Try next option
    │
    ├─ OPTION C: Start CONTAINER LM Studio anyway
    │   │
    │   ├─ docker compose up -d lmstudio
    │   │
    │   ├─ Wait 5 seconds
    │   │
    │   ├─ IF running now?
    │   │   └─ ✅ YES → Use CONTAINER
    │   │   └─ (will crash on model load, but monitored)
    │   │   └─ Continue
    │   │
    │   └─ IF still crashed → Try next option
    │
    └─ OPTION D: Graceful Degradation
        │
        ├─ ⚠️  NO LM Studio available
        │
        ├─ Use Memory MCP + Watcher MCP
        │
        ├─ Log: "LM Studio unavailable, operating in reduced mode"
        │
        └─ Continue anyway
            └─ System still operational, just degraded
