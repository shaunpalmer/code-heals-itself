## 🔍 AUDIT CHECKLIST

### 1. Search for Legacy MCP Code
Run these searches in VS Code or terminal:

```bash
# Find all folders with 'mcp' in name
find . -type d -name "*mcp*" -o -name "*agent*" -o -name "*model*"

# Find old config files
find . -name ".env" -o -name "config.json" -o -name "*.yaml" | grep -v docker-compose

# Find hardcoded endpoints
grep -r "localhost:1234" --include="*.py" --include="*.js" --include="*.ts" --include="*.php"
grep -r "localhost:8090" --include="*.py" --include="*.js" --include="*.ts" --include="*.php"
grep -r "PORT\s*=" --include="*.py" --include="*.js" --include="*.ts"

# Find Flask/FastAPI/Express app definitions
grep -r "app\.run\|uvicorn\|express\(" --include="*.py" --include="*.js" --include="*.ts"
```

For each discovery, note:
- **File/Folder Path**: e.g., `./mcp/old_memory_service/`

- **Port Used**: e.g., 8090, 5001, 3000

### 3. Categorize Conflicts

| Category | Action | Notes |
|----------|--------|-------|
| **Duplicate Service** | Move to `/agents/<name>/` | If it's still useful, Dockerize it |

| **Hardcoded Endpoint** | Update to network name | Change `localhost:8090` to `memory-mcp:8090` |
| **Port Conflict** | Reassign or migrate to Docker | Ensure no manual service runs on 5000, 8090, 8091, 1234 |

## 🧩 REFACTORING RULES

### For Services Still Needed:

1. **Move to Docker**:
   ```
   OLD: ./mcp/my_service/app.py
   NEW: ./agents/my_service/app.py
   NEW: ./agents/my_service/Dockerfile
   ```

2. **Update Imports**:
   ```python
   # OLD
   from mcp.config import settings
   # NEW
   from config import settings  # Relative path inside container
   ```

3. **Use Docker Network Names**:
   ```python
   # OLD
   response = requests.get("http://localhost:8090/memory")
   # NEW
   response = requests.get("http://memory-mcp:8090/memory")
   ```

4. **Environment Variables**:
   ```yaml
   # Add to docker-compose.yml under the service
   environment:
     - MCP_NAME=MyMCP
     - LM_STUDIO_URL=http://lmstudio:1234/v1
     - DATA_PATH=/data
   ```

5. **Create Dockerfile**:
   ```dockerfile
   FROM python:3.12-slim
   WORKDIR /app
   COPY app.py .
   RUN pip install --no-cache-dir fastapi uvicorn
   EXPOSE 8092  # New unique port
   CMD ["uvicorn", "app:app", "--host", "0.0.0.0", "--port", "8092"]
   ```

6. **Register in docker-compose.yml**:
   ```yaml
   my-service-mcp:
     build:
       context: ./agents/my_service
       dockerfile: Dockerfile
     container_name: code-heals-my-service-mcp
     ports:
       - "8092:8092"
     volumes:
       - ./data:/data
     environment:
       - MCP_NAME=MyServiceMCP
     networks:
       - healing-network
   ```
